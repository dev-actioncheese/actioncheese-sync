# ActionCheeseSyncKit

The ActionCheese Sync engine as a Swift package: waveform-based alignment of
audio recordings, with no ffmpeg, no Python and no third-party dependencies —
AVFoundation for decoding, Accelerate for the maths.

It is a port of the Python engine in `../../src/syncmyvids`, and it is kept
honest by parity tests that check it against golden data generated by that
engine (`Tests/ActionCheeseSyncKitTests/Golden/golden.json`).

## Use

```swift
let result = try await ActionCheeseSync.sync(
    anchors: anchors,        // clips whose position is already known
    candidates: candidates,  // clips to place
    options: .init(minConfidence: 0.45)
)
```

Anchors are held exactly fixed: they are substituted out of the least-squares
system rather than weighted heavily, so a known position stays bit-for-bit
known.

Each candidate comes back as `.placed(start:confidence:driftPPM:)` or
`.unmatched(reason:)`. Nothing is ever silently dropped.

## Tests

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
```

Some tests need the sample media referenced by the golden data; they skip
cleanly when it is not mounted.
